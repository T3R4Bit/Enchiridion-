# Enclosure

Handheld shell for Enchiridion, modeled in Fusion 360.

- Form factor comparable to a Baofeng UV-5R.
- Houses a single 18650 cell.
- 3D-printed in PETG or ABS.
- Driven by `.STEP` exports from the KiCad board so cutouts for the display,
  USB-A, USB-C, SD slot, and buttons line up with the PCB.
